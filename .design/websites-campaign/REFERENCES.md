# References — curated (Fable review of the hunt, 11 Aug)

Full agent report archived in session. What we're adopting, and why; rejected items noted so we don't re-litigate.

## Adopted

1. **Price + slots as one plain sentence in running text** (Marbury's register + Common/Springwave's real counter). Serif figure in text. NEVER a pricing card, strikethrough anchor, or countdown. → hero + §8.
2. **Scarcity = a literal counter tied to the real cap with a stated reason** ("five, because that's what we can build well"). Common's "04 accepted / 02 available" mechanic in TSS clothes: quiet mono line, e.g. `FIVE SLOTS · THREE REMAIN`. → hero eyebrow + §7 slot calendar.
3. **Motion as punctuation, not spectacle** (Active Theory lesson + 2026 award-circuit shift away from scroll-jacking): one tuned hero reveal, one display moment for the differentiator line, house fade/stagger elsewhere. Copy-heavy editorial pages die by animation. → build.
4. **Proof = name + one concrete outcome line + chrome-free full-bleed screenshot** (basement.studio outcome sentences + Bejamas hard-metric habit + Locomotive clean cards). No browser bezels, no device mockups, no logo walls. Tuisa card: "Live inside a week." → §3. *(Overrides the brief's "browser-hinted frame" note.)*
5. **Inclusions/exclusions as declarative ledger prose under mono eyebrows** (Designjoy's two-sided structure, stripped of SaaS icon/checkmark chrome). → §4/§5.
6. **Hero voice model: one flat declarative sentence** (Bakken & Bæck's "We build digital products, from zero to launch"). Confirms hero options A–D's register; no wordplay stacking.

## Rejected

- Client logo walls / rosters (basement, B&B, Ramotion): volume signal contradicts a five-slot offer.
- Comparison tables "Agency vs DIY vs Us" (Common): SaaS pricing trope. The freelancer/agency comparison lives in §2 as prose, where it's a story.
- Strikethrough pricing, "limited time" labels (Designjoy): the exact discount-sale register the doc forbids.
- Custom cursors, hover physics, WebGL (Cuberto, Active Theory): wrong budget, wrong point; the page sells words.
- Emoji headers, checkmark benefit lists, "don't wait" (Springwave): growth-hack register.
- Testimonial sections with headshots (Ramotion): we have zero real testimonials on file; nothing gets fabricated.
